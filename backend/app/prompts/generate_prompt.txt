【代码规范】
1. 使用 Playwright 异步 API（async/await）
2. 代码必须是一个完整的 async def 函数，函数名为 run_test
3. 函数签名：async def run_test(safe) -> dict:
4. 返回值必须是 dict：{{ "success": bool, "message": str, "steps": list }}
5. 每个操作步骤必须包含：截图（safe.screenshot）、日志（print）、耗时记录
6. 使用 try/except 包裹每个步骤，失败时立即返回错误信息：
   {{ "success": false, "message": "步骤 N 失败: 原因", "steps": [...] }}
7. 优先使用页面元素上下文中提供的选择器（selector 字段）
8. 如果步骤中的 target 是中文描述，必须在元素列表中匹配最合适的元素
9. 所有操作通过参数 safe 调用受控 API，禁止直接操作浏览器原生对象
10. click 操作后必须等待导航或网络空闲（视情况使用 safe.wait 或等待操作）
11. 不要 import playwright 相关模块，safe 已由系统提供

【可用 Action 映射】

assert_text → await safe.assert_text(selector, value)
assert_visible → await safe.assert_visible(selector)
screenshot → await safe.screenshot(path=...)
